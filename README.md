# MarketMind-AI
This repo is solely used for recording the project reproducing and modifications making. Not for any publication or commercial use.
### My Approach
Based on Trading Agent, I combined more data sources like yfinance, SeekingAlpha, Alpha Vantage, SEC EDGAR fillings (10-K/10-Q) and earnings-call transcripts for fundamentals, in order to analyse the company's recent and forward-looking trajectory.

This project is a multi-agent LLM workflow used a lot of customized prompt learning, function calling skills. This MarketMind AI is more persuasive in analyzing the data of the US stock market, if you want to analyse companies from China(CN), Korea(KR), Japan(JP) or somewherelse, more reliable data source is required.
